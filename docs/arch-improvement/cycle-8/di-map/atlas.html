Почему здесь несколько схем

По C4/arc42: статические зависимости, сборочная конфигурация и runtime-сообщения — разные виды. Нельзя читать стрелку импорта как поток исполнения. Type-only и manifest-only зависимости не рисуются как активное runtime-подключение.

  • C4 notation: title, legend, typed/labelled relationships
  • C4 FAQ: SDKs and focused diagrams
  • arc42 building block view — static dependencies
  • arc42 runtime view — scenario interactions

Область охвата: Все workspace packages + публичные assembly options, PiRuntimeDependencies, builtin/resource/model/storage/host/transport/UI seams. Не все транзитивные npm packages и не каждый private helper SDK.

Source-traced atlas. Внешние сервисы/модели не запускались. Source status не подменяет acceptance tests. Код графиков и JSON доступны рядом.
